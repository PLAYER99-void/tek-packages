# tek-packages

Binary packages for [Tek OS](https://github.com/PLAYER99-void/tek-os), built by CI inside the Tek system
and installed with `tek -S <name>`. Do not edit by hand: every publish replaces this branch.

Add this to `/etc/tek/tek.conf`:

    repo = tek https://raw.githubusercontent.com/PLAYER99-void/tek-packages/main/x86_64
